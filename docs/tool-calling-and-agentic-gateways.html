Architecture & Reference

The Definitive Guide to Tool Calling, Function Calling & Agentic Gateways

A complete engineering guide on how autonomous coding agents (Claude Code, Cursor, Cline, Aider) interact with LLMs, and how an LLM Gateway orchestrates them.

1. Foundational Concept: How Agents Actually Work

The Common Misconception: Many developers believe that when they use Claude Code or Cursor, the LLM itself is running terminal commands, navigating directory trees, or editing code directly on their system.

The Reality: No LLM can run code, open files, or access the network. An LLM is strictly a mathematical next-token prediction engine that evaluates text in and produces text out.

The Two Halves of an Autonomous System

  • The Agent (The Host Application / Pilot): A local program on your OS (Cursor IDE, Cline VS Code Extension, or Claude Code CLI) with access to fs.readFile, fs.writeFile, and terminal shells.
  • The LLM Gateway / Model (The Brain / Engine): Receives the prompt, identifies missing information, and emits structured JSON instructions directing the host program which function to execute.

2. The 3-Step Lifecycle of a Tool Call

  1. Step 1: Request with Tool Declarations — The client sends the user message along with a JSON Schema array of tools the agent can execute (e.g. run_bash, read_file).
  2. Step 2: Model Decision (Tool Call Emission) — The LLM responds with content: null and a structured tool_calls object containing the function name and serialized JSON arguments.
  3. Step 3: Tool Execution & Feedback Loop — The agent executes the command on your operating system and sends the output back in a follow-up request with role: "tool". The LLM then answers the user using that output.

3. The OpenAI Standard Payloads

Step 1: The Request Payload (Sending Tools)

{
  "model": "smart-chat",
  "messages": [
    { "role": "user", "content": "What files are in the current directory?" }
  ],
  "tools": [
    {
      "type": "function",
      "function": {
        "name": "run_bash",
        "description": "Execute a command in the local shell",
        "parameters": {
          "type": "object",
          "properties": {
            "command": { "type": "string", "description": "e.g. 'ls -la' or 'dir'" }
          },
          "required": ["command"]
        }
      }
    }
  ]
}

Step 2: The Model's Response (Emitting the Call)

{
  "choices": [
    {
      "message": {
        "role": "assistant",
        "content": null,
        "tool_calls": [
          {
            "id": "call_01j7k8m9",
            "type": "function",
            "function": {
              "name": "run_bash",
              "arguments": "{\"command\":\"dir\"}"
            }
          }
        ]
      },
      "finish_reason": "tool_calls"
    }
  ]
}

Step 3: The Host Returns Execution Output

{
  "model": "smart-chat",
  "messages": [
    { "role": "user", "content": "What files are in the current directory?" },
    {
      "role": "assistant",
      "tool_calls": [{ "id": "call_01j7k8m9", "function": { "name": "run_bash", "arguments": "{\"command\":\"dir\"}" } }]
    },
    {
      "role": "tool",
      "tool_call_id": "call_01j7k8m9",
      "content": "apps  packages  package.json  turbo.json  README.md"
    }
  ]
}

4. How Providers Differ: What Adapters Must Translate

Feature OpenAI / Groq Google Gemini Anthropic Claude
Tool Schema tools: [{ type: "function", function }] tools: [{ functionDeclarations: [...] }] tools: [{ name, input_schema }]
Tool Output message.tool_calls: [...] parts[0].functionCall content: [{ type: "tool_use" }]
Tool Result role: "tool", tool_call_id parts[0].functionResponse content: [{ type: "tool_result" }]

5. Streaming Tool Calls (SSE)

During streaming (stream: true), tool call arguments are sent as character fragments across multiple Server-Sent Events:

data: {"choices":[{"delta":{"tool_calls":[{"index":0,"id":"call_99","function":{"name":"run_bash"}}]}}]}
data: {"choices":[{"delta":{"tool_calls":[{"index":0,"function":{"arguments":"{\"comm"}}]}}]}
data: {"choices":[{"delta":{"tool_calls":[{"index":0,"function":{"arguments":"and\":\""}}]}}]}
data: {"choices":[{"delta":{"tool_calls":[{"index":0,"function":{"arguments":"npm test\"}"}}]}}]}
data: {"choices":[{"delta":{},"finish_reason":"tool_calls"}]}
data: [DONE]
